# OmniAI Desktop - Releases

Public downloads for **OmniAI Desktop**, a multi-webview AI aggregation workbench
(Rust + Tauri 2 + WebView2). Up to 6 independent AI panels in one native window,
each with its own persistent login/cookies; quick-bar bookmarks with drag-to-reorder.

> Source code is closed. This repository hosts public releases only.

## Latest: v0.1.0
Download the portable (no-install) build from the [Releases](../../releases) page:
`OmniAI-Desktop_0.1.0_x64-portable.exe` - just run it.

Requires Microsoft Edge WebView2 Runtime (usually preinstalled on Windows 11).
Self-signed: if SmartScreen appears, choose "More info -> Run anyway".
